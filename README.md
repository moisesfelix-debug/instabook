# InstaBook

Plataforma SaaS para criação, planejamento, aprovação, agendamento e análise de conteúdo para Instagram com IA, preparada para uso individual e operação de agência.

## Stack inicial

- Next.js
- TypeScript
- Supabase
- Vercel
- IA via API

## Estado atual

Base inicial do produto e documentação de arquitetura. O próximo passo é conectar autenticação, banco multi-tenant, marcas e workspaces.
